# Distrikt Marquet Interviews

Transkripte der Interviews vom Dreh am 3. November 2026 im Distrikt Marquet, FOUR Frankfurt.
Totale von der FX3 mit der LUT DIN.CLD.002, Ton vom Ansteckmikro, transkribiert mit Whisper large-v3-turbo.

Statische Seite ohne Build: `index.html`, `style.css`, `app.js`, Daten in `daten/interviews.json`.
Die Daten baut `daten_bauen.py` im Arbeitsordner aus den Whisper-Transkripten.
